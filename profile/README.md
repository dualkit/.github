Free, open-source tools for products that ship in Arabic and English.

- **[Skills](https://github.com/dualkit/dualkit/tree/main/skills)** teach Claude Code and Cursor to get Arabic right: RTL layout, type pairing, Gulf formats and bilingual copy.
- **[Format](https://github.com/dualkit/dualkit/tree/main/packages/format)** handles AED and SAR, Hijri dates, Arabic numerals, UAE phone numbers, Emirates ID and Gulf IBANs, with no dependencies.
- **[Starter](https://github.com/dualkit/dualkit/tree/main/packages/starter)** is a bilingual design system to fork, one token file for code and Figma.

Start at **[dualkit/dualkit](https://github.com/dualkit/dualkit)** or [dualkit.dev](https://dualkit.dev).
